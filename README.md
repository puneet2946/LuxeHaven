◈ About the Project

LuxeHaven is a luxury real-estate website created to bring premium properties and refined living experiences together in one place.

Inspired by modern real-estate platforms, the website features an elegant visual identity, sophisticated typography, curated property listings, and a multi-page browsing experience.

The project focuses on applying fundamental web development concepts using HTML, CSS, and JavaScript.

Our Vision

To create a digital property discovery experience that feels as exceptional as the homes it showcases.

⚙️ JavaScript Functionality

JavaScript brings interactive behavior to the website while demonstrating fundamental DOM concepts.

Current functionality includes:

* Dynamic Footer Year: Retrieves the current year and updates the footer automatically.
* Homepage Search Interaction: Reads the entered location and provides search feedback.
* Search Form Interaction: Displays a message based on the user’s search input.
* Login Interaction: Demonstrates basic interaction with the login form.
* Property Card Highlighting: Adds a CSS class to highlight a selected property card.

These features demonstrate concepts such as getElementById(), onclick, textContent, classList.add(), variables, functions, and conditional statements.

Note: The website is a frontend project. Search interactions are demonstrations rather than a complete property search engine, and the login interface does not provide real authentication or backend account management.

🚀 Getting Started

You can run LuxeHaven locally in just a few steps.

Prerequisites

* A modern web browser.
* Visual Studio Code or another code editor.
* The project files, including the images folder.

Installation

1. Clone the repository

git clone https://github.com/puneet2946/LuxeHaven.git

2. Open the project folder

cd LuxeHaven

3. Open the website

Open LuxeHaven.html in your browser, or use the Live Server extension in Visual Studio Code.

4. Explore the website

Navigate between the homepage, property listings, gallery, search interface, and login page.
